# Next Gen Coders - Futuristic Website

A stunning futuristic website built with pure HTML, CSS, and JavaScript featuring a liquid glass design aesthetic.

## ✨ Features

- **Liquid Glass Design**: Beautiful glass morphism effects with backdrop blur
- **Futuristic Aesthetics**: Gradient backgrounds, glowing elements, and smooth animations
- **Responsive Layout**: Works perfectly on all devices from mobile to desktop
- **Interactive Elements**: Hover effects, smooth scrolling, and dynamic animations
- **Modern Typography**: Inter font with gradient text effects
- **Performance Optimized**: Lightweight and fast loading

## 🚀 Quick Start

### Option 1: Python Server (Recommended)
```bash
# Navigate to the website directory
cd simple-website

# Start the server
python3 server.py
```

The website will automatically open in your browser at `http://localhost:8080`

### Option 2: Live Server (VS Code)
1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

### Option 3: Simple HTTP Server
```bash
# Navigate to the website directory
cd simple-website

# Start a simple server
python3 -m http.server 8080
```

Then open `http://localhost:8080` in your browser.

## 🔧 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-cyan: #00f5ff;
    --primary-purple: #8b5cf6;
    --primary-pink: #ec4899;
    --accent-gold: #fbbf24;
}
```

### Content
- Edit `index.html` to change text content
- Modify `styles.css` to adjust styling
- Update `script.js` to add new interactions

### Animations
- Adjust animation speeds in `script.js`
- Modify keyframes in `styles.css`
- Add new effects by extending the JavaScript
