# XDIGIX Finance App

Finance-focused app: overview, transactions, payments, expenses, accounts, budgets, reports, taxes, capital, settings, audit. Data from backend API (MongoDB).

**Source to extract from:** `sys/apps/marketing/apps/finance/`. Unify with dashboard finance pages; one API.

**Stack:** React + Vite. Uses `@xdigix/design-system`. API-only; no Firebase.

**Routes:** login, overview, transactions, payments, expenses, accounts, budgets, reports, taxes, capital, settings, audit.
