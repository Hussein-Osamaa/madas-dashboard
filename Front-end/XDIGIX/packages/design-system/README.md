# @xdigix/design-system

Shared UI for XDIGIX: tokens (colors, spacing, typography, radii) and components (buttons, cards, tables, modals, forms, badges, layout). Used by marketing, dashboard, digix-admin, finance, fulfillment.

**Contents:**
- `src/tokens/` – CSS variables or Tailwind theme (colors, spacing, typography, radii)
- `src/components/` – Buttons, Card, Table, Modal, Form inputs, Badge, AppShell, Sidebar, Header

**Consumption:** Apps import components and tokens; same look and behavior everywhere.
